# Info Lab OSINT Tools | Tiktok

## Linux

Clone the repository:

```bash
git clone https://github.com/keyid705-oss/osint-tools.git
cd osint-tools
```

Run the TikTok URL Inspector:

```bash
python3 "Tiktok URL Inspector.py"
```

If `python3` doesn't work, try:

```bash
python "Tiktok URL Inspector.py"
```

## Windows

Clone the repository:

```powershell
git clone https://github.com/keyid705-oss/osint-tools.git
cd osint-tools
```

Run the TikTok URL Inspector:

```powershell
py "Tiktok URL Inspector.py"
```
